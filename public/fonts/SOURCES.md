# Involve heading font

`Involve-SemiBold.woff2` (normal, weight 600) was downloaded from the Spaciaz demo's declared font resource:

https://demo2.wpopal.com/spaciaz/wp-content/themes/spaciaz/assets/fonts/new/Involve-SemiBold.woff2

The original resource is served locally for the Rahat Associates upright headings. The fallback family stack remains in place; blue italic text uses Playfair Display.
